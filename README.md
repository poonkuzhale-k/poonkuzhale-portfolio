# Poonkuzhale Kulasekaran — Portfolio

A single-page responsive portfolio built with pure HTML, CSS and JavaScript.

## Files
- index.html
- style.css
- script.js
- poonkuzhale-profile.png

## Run locally
Open `index.html` in Chrome/Edge/Firefox.

## GitHub Pages
1. Create a new GitHub repository, e.g. `poonkuzhale-portfolio`.
2. Upload all four files to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will provide the live Pages URL.

## Important
The profile photo filename expected by `index.html` is:
`poonkuzhale-profile.png`

Keep that file in the same folder as `index.html`.
